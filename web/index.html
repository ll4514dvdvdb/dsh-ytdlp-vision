cookies.txt

怎么用

  1. 只给需要的站点填。B 站最常用：登录后按 F12 → Application → Cookies → bilibili.com，复制 SESSDATA（以及可选的 bili_jct、buvid3）。
  2. 也可以把浏览器里整串 a=b; c=d 粘到卡片下方的输入框，点「解析并填入」。
  3. 保存后立即生效：B 站走这里配置的登录态（1080P、CC 字幕、会员清晰度），其它站点由 yt-dlp 带着 cookies.txt 抓取。

这些值是账号凭据，等同于你的登录状态。文件只存在本机（…，权限 0600），页面本身也只监听回环地址；不要截图外传，也不要把这个文件同步到网盘。

整串粘贴

支持两种格式：浏览器里复制的 name=value; name2=value2，或 Netscape cookies.txt 的行。

从浏览器直接读

开启后 yt-dlp 用 --cookies-from-browser 现场读取浏览器 cookie，不经过本文件（优先级高于下面的配置）。

注意：Firefox 需要浏览器不在运行；Chromium 系在 Windows 上要用当前用户同一会话运行，否则读不到加密库。

自定义站点

预设里没有的站点在这里加：给一个短 id（如 netease）和它的 cookie 域。

站点不在上面的预设里、或需要按域精确指定时用。每行 domain TRUE / TRUE 4070908800 name value，制表符分隔。
