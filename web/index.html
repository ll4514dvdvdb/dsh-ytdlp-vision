从浏览器直接读

开启后 yt-dlp 用 --cookies-from-browser 现场读你日常浏览器的 cookie，不经过本文件（优先级最高）。

自定义站点

预设里没有的站点：给一个短 id 和它的 cookie 域，也可以直接用上面的「生成」抓。

额外的 Netscape 行

需要按域精确指定时用。每行 domain TRUE / TRUE 4070908800 name value，制表符分隔。

这些值是账号凭据，等同于你的登录状态。文件只存在本机（…，权限 0600），页面只监听回环地址；不要截图外传，也不要同步到网盘。
